# 시사 Windows 공유본 — 0.3.2

타이핑 우사기(USAGI Desktop Pet)와는 별개의 **할 일·일정·대화 비서, 시사**입니다.

이 저장소는 [cheo0y/shisa-agent](https://github.com/cheo0y/shisa-agent)의 **Windows 0.3.2, 2026-10-19 재배포본**을 공유하기 위한 비공식 보관본입니다. 제작자는 원본 프로젝트의 기여자들이며, 이 저장소는 새 프로그램을 개발한 프로젝트가 아닙니다.

## 바로 설치하기

**Codex로 설치하려면:** [Codex용 설치 안내 Markdown](INSTALL_WITH_CODEX.md)을 전달하고 “이 파일대로 시사를 설치해줘”라고 요청하세요.

### [⬇ Windows 설치 파일 받기](https://github.com/jangyunseo-ineeji/shisa-windows-share/releases/download/v0.3.2-share.1/Shisa-0.3.2-Setup.exe)

1. 위 링크에서 `Shisa-0.3.2-Setup.exe`를 받습니다.
2. 이미 시사가 실행 중이면 시계 옆 알림 영역의 시사 아이콘에서 **종료**합니다.
3. 설치 파일을 실행한 뒤 바탕화면 또는 시작 메뉴의 **시사**를 엽니다.
4. 처음 실행하면 이름과 필요한 기능을 설정합니다. AI 없이도 기본 할 일·집중·알림 기능을 이용할 수 있습니다.
5. 대화 기능을 쓰려면 **본인의 AI 계정 또는 API 키**를 연결합니다. 캘린더·메일 등은 원하는 경우에만 연결합니다.

**지원 환경:** Windows 10/11 64비트. 설치 프로그램에는 실행에 필요한 구성요소가 포함됩니다. 회사 PC에서 설치가 차단되면 보안 설정을 해제하지 말고 담당자에게 문의하세요.

## 무엇이 들어 있나요?

- **설치 파일:** 원작자가 배포했던 0.3.2 설치 파일 그대로입니다. 그림·영상 등 기존 캐릭터 리소스도 이 원본 설치 파일에 포함되어 있습니다. 수정하거나 다시 패키징하지 않았습니다.
- **소스:** 실제 설치본에 대응하는 원본 커밋 `b9c83cbbd575a984b49310b9e9c50f49983106a6`의 프로그램 코드입니다.
- **설치·사용 안내:** 처음 설치하는 사람을 위한 안내와 원본 문서입니다.
- 공유자의 할 일, 대화 기록, 캘린더 주소, 개인 설정, AI 로그인 정보, API 키는 포함하지 않습니다. 받는 사람은 자신의 환경으로 새로 시작합니다.

현재 최신 기능을 담은 버전이 아니라 **공유자가 사용하던 0.3.2 환경을 재현하기 위한 보관본**입니다. 최신 공식 버전은 [원본 Releases](https://github.com/cheo0y/shisa-agent/releases)에서 확인할 수 있습니다. 이 저장소는 자동 업데이트를 제공하지 않습니다.

## 기본 사용

- 캐릭터 한 번 클릭: 패널 열기
- 캐릭터 두 번 클릭: 대화
- 캐릭터 오른쪽 클릭: 메뉴
- 할 일 줄의 **⋮⋮ 손잡이**: 순서 변경 또는 우선순위 묶음 사이 이동
- 우선순위 **오늘 꼭**: 오늘 할 일
- 종료: Windows 알림 영역의 시사 메뉴 → 종료

자세한 내용은 [원본 사용 설명서](README.upstream.md), [Windows 안내](windows/README.md)를 참고하세요. 원본 문서는 해당 시점의 기록이며, 일부 외부 링크나 AI 모델 안내는 이후 바뀔 수 있습니다.

## 데이터 저장과 기존 사용자

각자의 할 일·대화·설정은 각자의 PC `%USERPROFILE%\.cy-agent`에 저장됩니다. 기존 시사 사용자는 해당 폴더를 먼저 백업하세요. 이 설치 파일은 기존 데이터를 초기화하기 위한 도구가 아닙니다.

새 버전(예: 0.4.0)을 이미 사용하는 PC에 이 보관본을 덮어 설치하는 다운그레이드는 검증하지 않았습니다.
